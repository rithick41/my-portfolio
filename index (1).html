How I troubleshoot

  2. Check the basics firstCables, link lights, IP address and subnet mask.
  3. Test in layersPing the device, then the gateway, then another host.
  4. Fix, confirm and documentVerify the fix with the user and record it for the next person.

Own project

Local LAN for a small office

I designed and built a local area network in Cisco Packet Tracer so multiple computers in a small office can communicate and share resources. It uses a 2911 router, a 2960 switch, a DHCP server and five PCs.

  • Connected the router, switch, DHCP server and five PCs (PC2 to PC6) in a star topology.
  • Set up a DHCP server so every PC receives its IP address, subnet mask and gateway automatically.
  • Tested connections and troubleshot connectivity issues to keep communication and resource sharing reliable.
